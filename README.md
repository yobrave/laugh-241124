# The One-Line Laugh

One funny line of at most 200 characters on any subject — the house judge keeps the bigger laugh. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
